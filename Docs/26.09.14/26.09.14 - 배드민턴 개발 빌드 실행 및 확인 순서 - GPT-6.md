# 배드민턴 개발 빌드 실행 및 확인 순서

작성일: 2026-09-14 · 작업 모델: GPT-6

## 준비

- 이 문서는 현재 로컬 프로토타입의 실행 안내다. 실제 EOS 외부망 연결 완료를 뜻하지 않는다.
- `Start-BadmintonPackage.cmd`는 패키징 결과가 생성된 후 사용한다. 패키징 결과/미완료 여부는 같은 날짜의 구현 기록을 먼저 확인한다.
- `Scripts/Package-Badminton.ps1`은 Windows Development 빌드와 코트 맵 쿠킹·패키징을 수행한다. 출력은 `Saved/Packages/BadmintonMVP/Windows`다.
- CMD 실행기는 현재 PC에 설치된 PowerShell 7 경로를 사용한다. 다른 PC에서는 실행 파일과 전체 패키지 폴더를 함께 복사한다. `LocalSecrets`는 복사 대상이 아니다.

## 동일 PC에서 2인 실행

1. `Start-BadmintonPackage.cmd`를 실행하고 2번 호스트를 선택한다.
2. 다시 실행하고 3번 참가를 선택한다.
3. 각 게임 창에서 Enter를 눌러 준비한다. 서브권이 있는 쪽이 왼쪽 클릭으로 서브한다.
4. WASD로 셔틀 가까이 이동하고 왼쪽 클릭으로 클리어한다. 오른쪽 클릭은 드롭, Space는 스매시, Shift는 대시다.
5. 11점에 경기가 끝나면 양쪽 Enter로 재경기한다.

혼자 코트 열기는 상대를 기다리는 모드다. AI나 1인 훈련 모드는 구현하지 않았다. 높은 공만 스매시할 수 있고, 거리·높이·코트·랠리 조건이 맞지 않으면 헛스윙한다. 승인된 헛스윙의 스태미나 비용도 소비된다.

## 다른 PC의 직접 IP 접속

같은 LAN의 호스트 IP를 확인한 다음 PowerShell 7에서 `Scripts/Start-BadmintonPackage.ps1 -Mode Join -Address 호스트IP:7777`을 실행한다. 다른 PC에서 패키지 실행 파일을 직접 실행하는 경우에는 실제 내부 게임 exe에 `호스트IP:7777 -windowed -ResX=1280 -ResY=720` 인수를 준다.

직접 IP 방식은 인터넷 방 목록/NAT 통과 검증과 구분한다. 방화벽·라우터 변경이 필요하면 사용자 확인 목록에 기록하고 자동 변경하지 않는다.

## EOS 연결 확인

1. 이 PC에서 비밀 키를 보관한 사용자 계정으로 실행한다.
2. `Start-BadmintonEOS.cmd`는 에디터 기반 개발 실행, `Start-BadmintonPackage.cmd`의 4번은 패키징 실행이다.
3. F1 로그인 → 브라우저에서 직접 Epic 인증/동의 → 호스트 F2 방 생성 → 참가자 F3 검색 → F4 첫 방 참가.
4. 참가할 방을 번호로 고르려면 콘솔 `BadmintonEOSJoin 번호`를 사용한다. F5는 방 나가기다.
5. 두 개의 서로 다른 Epic 계정과 개발 애플리케이션 접근 권한이 필요하다. 이 실제 검증은 아직 사용자 확인 대기다.

`Scripts/Start-BadmintonEOS.ps1 -ConfigurationTest`의 성공은 합성 값으로 런타임 INI를 읽었다는 뜻이다. 실제 계정 로그인이나 인터넷 연결 성공이 아니다. 비밀 키를 채팅이나 문서에 붙여 넣지 않는다.

## 영상 및 플레이테스트

실제 Windows 녹화 프로그램으로 게임 화면만 녹화하고 `Docs/_녹화파일/26.09.14 - 단계 및 테스트 제목 - GPT-6.mp4` 형식으로 저장한다. 인증 화면과 비밀 키 입력은 녹화 대상에서 제외한다. 현재 실제 MP4 시연은 미완료다.

아래 항목은 자동화 결과와 별도로 사람이 확인해야 한다.

- 샷별 높이·거리와 대시·스태미나의 체감, 타격 타이밍과 상대 화면의 동기화.
- 실제 EOS 두 계정과 서로 다른 인터넷 연결에서 방 생성·참가·종료·재경기.
- 호스트 종료와 재접속 UX, 10경기 연속 플레이, 성능과 시각·음향 연출.
