# 플레이 HUD 및 GAS 조작 피드백 개선

작성일: 2026-09-14 · 작업 모델: GPT-6

## 요청 및 범위

사용자 요청: EQS 테스트를 나중으로 잠시 미루고 코딩 작업 시작. 이전 작업 기록의 대기 항목은 EOS 인증/외부망 테스트였으며, 이번에는 EQS와 EOS 테스트를 모두 실행하지 않는다. 기존 계획의 UI·연출 단계 중 외부 계정이나 최종 에셋 결정 없이 가능한 HUD를 구현한다.

## 진행 기록

- 기존 배드민턴 코드, 작업 기록, AGENTS.md 및 Git 상태를 확인했다. 작업 전부터 존재하는 변경은 보존한다.
- 화면에서 자기 점수·서브권·상대 준비 상태를 구분하도록 개선한다. 스태미나 막대와 능력별 사용 가능·회복 중·스태미나 부족 표시를 추가하며 기존 GAS 판정을 읽도록 연결한다.
- 고정 760px 정보 패널을 화면 비율에 따라 축소되는 상단 점수판·상태 안내·오른쪽 능력 카드로 바꾼다. 입력·서버 판정·점수 규칙은 이번 변경 대상에 포함하지 않는다.
- 경기 진행 중에는 온라인 방 목록을 숨겨 코트 가림을 줄이고 접속 종료 알림은 유지한다. 기존 영문 UI를 유지하며 최종 한글 폰트와 미술 에셋은 후속 사항이다.

## 검증 및 미완료

에디터/게임 빌드와 실제 렌더링 검증을 수행했다. 상세 결과는 아래에 기록한다. EQS/EOS 테스트는 보류. 현재 컴퓨터 제어 도구에서 네이티브 앱 제어가 비활성화되어 있어 PIE 조작 및 Windows MP4 녹화는 수행하지 않으며 별도 미완료로 기록한다. 기존 OBS 세션은 조작하지 않는다.

- 진행 갱신: 새 HUD의 에디터 빌드가 통과했다(Saved/Logs/BadmintonHUDBuild.log). 실제 렌더링에서 작은 창 배치와 서브 안내를 확인하고, 기존 경기 종료·재경기 검사로 상태 전환을 점검한다. 기존 실행 메뉴로 수정본을 실행할 수 있도록 게임 대상 빌드와 패키지 갱신도 진행한다.

- 검증 갱신: 편도 50ms·송신 패킷 손실 1%에서 2인 11점 경기 종료 및 0:0 재경기가 통과했다. 호스트·참가자 모두 결과를 관측했고 11개 랠리에 중복 득점이 없었다. 로그: Saved/Logs/BadmintonHost-20260914-110637-20510.log 및 BadmintonClient-20260914-110637-20510.log. 실제 RTT 계측값은 아니다.
- 시각 검토: 최초 1280x720 렌더링에서 하단 카드가 코트 후방을 가리는 것을 발견했다. 스태미나와 능력 카드를 오른쪽 2×2 배치로 옮겼으며, 배치 변경 후 에디터 빌드도 통과했다. 작은 창의 참가자 서브 대기 화면과 최종 패키지를 추가 확인한다.


- 960x540 실제 참가자 렌더링에서 YOU/OPPONENT 점수, RECEIVING/SERVING, OPPONENT’S SERVE 안내, WAIT 상태와 코트를 가리지 않는 오른쪽 카드 배치를 확인했다. 이미지: 26.09.14 - HUD 참가자 서브 대기 960x540 - GPT-6.png. 동일 실행의 양쪽 이동/ASC 프로브도 통과했다(Saved/Logs/BadmintonHUDSmallHost.log 및 BadmintonHUDSmallClient.log).
- 최종 게임 빌드 성공: Saved/Logs/BadmintonHUDGameBuild.log.
- 첫 패키지 조립은 엔진 Intermediate/Build/BuildCookRun/StagedBuild_FPS_Dell2g.ini 쓰기 권한 문제로 실패했다. 표준 패키징 도구의 해당 쓰기를 허용한 확장 실행으로 재시도하여 성공했다. 로그: Saved/Logs/BadmintonPackage-20260914-111203.log. 소스 코드만 변경되어 기존 쿠킹 에셋을 재사용했다.
- 기존 Start-BadmintonPackage.cmd가 사용하는 Saved/Packages/BadmintonMVP/Windows 패키지에 수정본을 반영했다. 실제 패키지 렌더링과 10회 교대 타격 검사를 진행한다.

## 남은 범위

- EQS 및 실제 EOS 계정/외부망 테스트는 사용자 요청을 반영해 보류했다. 기존 인증 오류를 해결했다고 표시하지 않는다.
- 이번 화면 변경은 기존 영문 프로토타입 폰트를 사용한다. 최종 캐릭터·라켓·애니메이션·사운드와 한글 UI는 별도 후속 범위다.
- RECOVERING/LOW STAMINA 분기와 승패·재경기 문구는 구현했다. 각 상태별 별도 스크린샷이나 사람의 조작 검증까지 완료한 것은 아니다. READY는 GAS 능력 발동 가능 표시이며 셔틀 접촉 성공 보장이 아니다.
- PIE 수동 조작과 Windows MP4 녹화는 네이티브 앱 제어 비활성화로 수행하지 못했다. 렌더링 검증은 RenderOffscreen 스크린샷으로 수행했으며 영상으로 대체 표기하지 않는다.
- git diff 공백 검사와 변경 HUD 파일의 줄 끝 공백 검사를 수행했다. 기존 추적 변경 외에 이 작업에서는 HUD 소스 두 파일, 작업/결정 문서와 화면 검토 이미지만 변경·추가했다. Docs는 기존 Git 제외 상태이며 커밋은 수행하지 않았다.

## 최종 전달 내용

HUD 개선 코딩을 완료했다. 자기 점수·상대 준비·서브 안내, 스태미나 막대와 GAS 능력 상태 표시를 추가하고 코트를 가리지 않도록 배치했다. 빌드·2인 경기·패키지 랠리 검증이 통과했으며 기존 Start-BadmintonPackage.cmd에 수정본이 반영되어 있다. EQS/EOS 테스트는 보류 상태로 유지한다.
