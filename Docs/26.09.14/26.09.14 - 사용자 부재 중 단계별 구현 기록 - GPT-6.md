## 요청 및 작업 범위

사용자가 쉬는 동안 결정이 필요한 사항은 별도 목록에 남기고, 결정이 필요하지 않은 작업부터 계속 진행하도록 요청했다. [결정 및 확인 필요 목록](<26.09.14 - 사용자 결정 및 확인 필요 목록 - GPT-6.md>)에 대기 사항을 기록했다.

확정된 개발 순서에 따라 샷 확장, 스태미나·대시, 서버 경기 규칙, 상태·결과 UI와 자동 검증을 진행한다. EOS 실제 계정 로그인·외부 권한 변경·외부 게시·구매는 보류한다. 실제 수행한 결과만 아래에 누적한다.

## 진행

- 기존 코드와 AGENTS.md를 확인했다. 현재 연습 랠리는 득점 없이 자동 리셋하므로 서버 점수·서브권·경기 종료 및 재경기 로직을 추가할 예정이다.
- Git의 기존 변경과 OBSRecording 소스를 보존한다. 현재 실행 환경에서 core.excludesFile=NUL 설정이 실패하여 기본 git 명령으로 상태를 확인했다.

## 구현 결과

- 서브·클리어·드롭·스매시·대시를 GAS 능력으로 구현했다. 드롭 8, 스매시 18, 대시 25의 스태미나를 한 번 소비하며 초당 12 회복한다. 기본 클리어와 서브는 무료다. 대시는 CharacterMovement의 Root Motion 작업으로 예측한다.
- `Content/Badminton/Data/DA_BadmintonShots.uasset`을 생성하고 GameState에서 참조한다. 샷 시간·목표·허용 높이·거리·회복 시간·비용과 대시 값을 에디터에서 조정할 수 있다. 비용 검사와 실제 차감이 같은 데이터의 값을 사용하도록 수정했다.
- 샷별 입력이 기본 타격 이벤트로 전달되는 오류를 발견하여 실제 선택한 이벤트 태그를 전달하도록 수정했다.
- 서버가 서브 구역, 네트 통과, 코트 안/밖, 득점, 서브권을 판정한다. 랠리당 한 번만 득점하며 11점에 종료한다. 두 플레이어가 다시 준비하면 점수와 스태미나를 초기화하고 재경기한다.
- 매 포인트마다 두 플레이어를 다음 서비스 위치로 이동시킨다. 종료·이탈·포인트 전환 시 진행 중 능력을 취소한다.
- HUD에 점수, 경기 종료·재경기, 서브권, 마지막 득점 이유와 샷별 비용을 표시했다. 존재하지 않는 강조 표시 안내와 숫자로만 표시하던 판정 이유를 수정했다.
- Windows 패키징 스크립트와 패키징 실행·EOS 실행 연결을 추가했다. 아래 패키징 결과와 별도로 실제 EOS 인증 여부는 계속 미검증이다.

## 실행·조작

- 기존 개발 실행: `Scripts/Start-Badminton.ps1 -Mode Host` 및 `-Mode Join -Address 127.0.0.1:7777`.
- 조작: WASD 이동, Enter 준비/재경기, 왼쪽 클릭 서브/클리어, 오른쪽 클릭 드롭, Space 스매시, Shift 이동 방향 대시(입력 방향이 없으면 전방).
- `Scripts/Test-BadmintonNetwork.ps1 -TestKind Movement|Rally|Match|Abilities`로 해당 검증을 실행한다. `-OneWayLagMs`, `-PacketLossPercent`, `-CheckCapacity`, `-CheckReconnect` 옵션을 제공한다.
- `Scripts/Package-Badminton.ps1`로 Windows Development 패키징한다. `Scripts/Start-BadmintonPackage.ps1 -Mode Solo|Host|Join|EOS`로 실행하도록 준비했다.
- 패키징 검증에는 `Test-BadmintonNetwork.ps1 -GameExecutable <실제 게임 exe>`를 사용할 수 있다.

## 제한 및 후속 사항

- 실제 Epic 계정 로그인과 두 계정의 EOS 방 생성·검색·참가, 외부망 테스트는 사용자 확인이 필요하다. 비밀 키는 읽거나 문서에 출력하지 않았다.
- `Saved/Screenshots/BadmintonPrototype.png`는 실제 렌더링 확인용 스크린샷이며 영상이 아니다. Windows Computer Use의 창 접근 승인이 시간 초과되었으므로 MP4 녹화는 미완료다. 실제 녹화 파일을 만들었다고 표시하지 않는다.
- 원시 도형 캐릭터와 코트다. 라켓·캐릭터 애니메이션, 사운드, 타격 이펙트와 손맛 튜닝은 남아 있다. 현재 기본 HUD는 영문이다.
- 현재 `.gitignore`는 Content와 Docs를 제외한다. 새 맵·DataAsset·문서는 디스크에 존재하지만 일반 Git 추가에 포함되지 않는다. 보존·추적 방식은 사용자 결정 목록에 남긴다.
- 실제 사람이 플레이하는 지연 보정 품질, 입력 지연·오차의 중앙값/상위 95% 계측, 10경기 연속 플레이와 별도 PC 검증은 아직 수행하지 않았다. 지연/손실 12개 조합의 자동 랠리 검사는 아래 최종 결과에서 완료했다.

- 추가 결과: 편도 75ms·손실 3%에서 같은 랠리의 10회 교대 타격 통과. 로그: BadmintonHost/Client-20260914-081702-19998.log.
- 패키징 초기 실패 원인: UAT 로그 폴더와 EngineSavedFolder가 쓰기 허용 범위 밖이었고, BuildCookRun의 -NoUBA가 UBT까지 전달되지 않았다. 런처에서 전용 프로젝트 내부 폴더와 -ubtargs=-NoUBA를 사용하도록 수정했다. 엔진 설치나 OS 보안 설정은 바꾸지 않았다.

- 추가 결과: 참가자 프로세스 종료 후 호스트가 1인 대기로 복귀하고 새 참가자가 접속하여 2인 준비 대기로 돌아오는 검사 통과. 로그: BadmintonHost-20260914-081936-19999.log 및 BadmintonRejoin-20260914-081936-19999.log. 호스트 종료 시 EOS 복구까지 검증한 결과는 아니다.
