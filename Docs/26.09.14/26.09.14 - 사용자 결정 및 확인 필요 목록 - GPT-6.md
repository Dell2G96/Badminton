# 사용자 결정 및 확인 필요 목록

사용자가 쉬는 동안 애매하거나 사용자 결정이 필요한 사항은 이 문서에 모으고, 이미 확정된 계획에 따라 독립 작업을 계속한다. 아래 항목의 응답을 기다리느라 로컬 구현을 중단하지 않는다.

| 상태 | 항목 | 필요한 결정 또는 확인 | 현재 처리 |
|---|---|---|---|
| 확인 필요 | 실제 EOS 로그인 | EOS_Auth_WrongClient 발생. 저장한 클라이언트 ID와 비밀 키의 조합 및 EAS 연동 클라이언트 일치 여부 | 비밀 키를 채팅에 보내지 않고 사용자 로컬/포털에서 확인. 자동 재발급·덮어쓰기 보류 |
| 대기 | 2인 EOS 테스트 계정 | 함께 테스트할 서로 다른 Epic 계정과 개발 앱 접근 권한 | 계정 생성·초대·조직 권한 변경 보류 |
| 대기 | 외부망 테스트 | 두 PC 또는 서로 다른 인터넷 연결 사용 가능 여부 | 동일 PC 별도 프로세스 검증 우선 |
| 후속 | 공개 배포용 브랜드 설정 | 실제 게임명, 소유 도메인, 웹사이트, 개인정보처리방침과 운영 주체 | 구매·외부 게시·브랜드 심사 제출 보류 |
| 후속 | 최종 시각·음향 에셋 | 캐릭터·라켓·코트 스타일 및 사용 가능한 에셋 | 기존 자산 보존, 개발용 기본 도형 사용 |
| 확인 필요 | 시연 녹화 | 도구에서 사용자 화면을 읽고 조작할 수 있는지, Windows 녹화 도구 실행 가능 여부 | 가능한 범위에서 실제 화면 녹화를 시도하되 실패 시 미완료로 기록 |

이미 확정된 1대1·11점 선취·듀스 없음·Listen Server·EOS 방 생성/참가 목표는 다시 질문하지 않는다. 샷 비용·속도 등 변경 가능한 밸런스 값은 개발용 기본값으로 구현하고 기록한다. 공식 배드민턴 규칙 전체와 동일하다고 설명하지 않는다.

- 추가 확인: 현재 Git 제외 규칙이 Content와 Docs를 제외한다. 새 맵·샷 DataAsset·문서의 추적/백업 방식을 정해야 한다. 기존 제외 규칙은 임의 변경하지 않았다.
- 녹화 상태 갱신: OBS Studio의 Badminton Tests 26.09.14 장면에서 게임 창 전용 녹화를 시작했다. 게임 창 접근은 승인 시간 초과 후 사용자의 물리 Escape로 Computer Use가 중단되었다. 마지막 확인 시 OBS 녹화가 진행 중이므로 사용자가 OBS의 녹화 중단을 눌러야 한다. MP4 변환 및 재생 검증은 미완료다.


- 2026-09-14 사용자 후속 요청: EQS 테스트는 잠시 보류하고 코딩 작업 진행. 이번 후속 작업에서는 기존 EOS 로그인/외부망 테스트도 재개하지 않고 HUD·GAS 조작 피드백 개선을 진행했다. EOS 인증 오류의 기존 확인 사항은 해결 완료가 아닌 보류 상태로 유지한다.
