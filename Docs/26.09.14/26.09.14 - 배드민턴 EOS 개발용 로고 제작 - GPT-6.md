# 배드민턴 EOS 개발용 로고 제작

작성일: 2026-09-14 · 작업 모델: GPT-6

## 요청과 규격

사용자가 전달한 포털 화면에서 애플리케이션 로고는 필수이며 최대 64KB, 128×128픽셀, JPG 또는 PNG를 요구하는 것을 확인했다. 저장을 위한 개발용 셔틀콕 로고를 제작했다.

## 수행 내용

imagegen 스킬과 내장 image_gen 도구로 원본을 생성했다. 업로드용 사본은 Windows System.Drawing으로 디자인 변경 없이 128×128픽셀로 축소하고 PNG로 저장했다. 생성 원본은 원래 위치에 보존했다.

- 업로드 파일: [26.09.14 - 배드민턴 EOS 로고 128px - GPT-6.png](<26.09.14 - 배드민턴 EOS 로고 128px - GPT-6.png>)
- 실제 크기: 128×128픽셀
- 실제 용량: 9,948바이트, 약 9.7KiB로 64KB 미만
- PNG 재열기 및 시각 검수로 파일 상태를 확인했다. 포털 업로드 및 저장 성공은 아직 미확인이다.

## 생성 프롬프트

Use case: logo-brand. Create one original app icon for a badminton multiplayer game, for use as an Epic Account Services development app logo. A single bold white shuttlecock silhouette, diagonal energetic orientation, with clean separated feather shapes and a small simple accent suggesting flight. Deep badminton-court green solid square background, crisp polished flat vector-like design, very high contrast, broad shapes readable at 128 by 128 pixels. Centered with generous safe margins. No words, letters, badges, mockup, border, Epic logo, or watermark. Deliver a square PNG suitable for a 128x128 pixel icon; if supported output exactly 128x128 pixels under 64KB.

## 최종 안내

규격에 맞는 개발용 로고를 만들었다. 포털의 `탐색`을 누르고 위 업로드 파일을 선택한 뒤 `초안 저장`을 누른다. 추가 필수 항목 오류가 나오면 해당 문구를 확인해 후속 조치한다. 브랜드 심사 제출이나 실제 포털 조작, 게임 테스트 및 녹화는 수행하지 않았다.

## 용량 제한 재확인 및 작은 JPG 제공

사용자가 `최대 파일 크기는 64 Kb입니다`라고 전달했다. 실제 업로드 대상으로 선택한 파일은 확인되지 않았으며 포털 오류 원인을 단정하지 않는다. 기존 PNG는 9,948바이트로 64KB보다 작지만, 64Kb를 64,000비트로 해석하는 경우에도 충족하도록 8,000바이트보다 작은 JPG를 추가했다.

- 파일: [26.09.14 - 배드민턴 EOS 로고 128px 용량축소 - GPT-6.jpg](<26.09.14 - 배드민턴 EOS 로고 128px 용량축소 - GPT-6.jpg>)
- 검증: 128×128픽셀, JPEG, 3,461바이트(약 3.5KB).
- 변환: 기존 로고 사본을 JPEG 품질 80으로 저장했다. JPEG는 투명도를 지원하지 않으므로 녹색 배경으로 합성했다. 기존 PNG와 생성 원본은 보존했다.
- 재열기와 시각 확인을 수행했다. 포털 업로드 성공은 아직 미확인이다.

최종 안내: 용량을 줄인 JPG를 포털의 `탐색`에서 선택한다. 이미지 생성 도구의 큰 원본 대신 이 JPG 파일을 업로드한다.
