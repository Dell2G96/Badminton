# 마우스 샷 조준 및 서버 목표 검증

작성일: 2026-09-14 · 작업 모델: GPT-6

## 요청과 선택 이유

사용자 요청: 다음 작업 진행. 초기 계획 3.2의 마우스 이동에 의한 상대 코트 목표 조정이 미구현임을 확인했다. 기존 샷은 고정 중앙 목표로 발사되므로 이동과 독립된 좌우·깊이 조준을 구현한다. EQS/EOS 테스트 보류는 유지한다.

## 진행 기록

- 현재 코드와 초기 계획, AGENTS.md, Git 상태를 확인했다. 관련 없는 변경은 보존한다.
- 마우스 좌우/상하 입력을 정규화된 두 축 조준값에 누적한다. 가운데 마우스 버튼으로 중앙 초기화하며 새 랠리에도 초기화한다. 캐릭터 이동과 카메라 회전은 기존 동작을 유지한다.
- 조준값을 GAS 타격 이벤트의 TargetData로 전송한다. 서버는 종류/개수/리터럴 위치/유한값/범위를 검증하고 DataAsset의 샷 프로필로 최종 목표를 계산한다. 서버 코트 좌표와 성공 여부는 클라이언트가 지정하지 않는다.
- 기존 궤적을 유지하기 위해 목표 지점은 샷 프로필의 TargetHeight에서 지나는 기준점이다. 코트의 AIM 표시는 방향·깊이 안내이며 실제 착지 예측이 아니다. 0,0 조준은 기존 목표를 유지한다.
- 기본 조준 폭 180cm, 깊이 변화 80cm를 DataAsset에서 조정할 수 있다. 서브 좌우는 대각 서비스 구역으로 제한한다. 기존 타격 조건과 비용은 유지한다.
- 화면 기준 방향이 양 코트에서 대칭인지, 서브 구역을 벗어나지 않는지, 비정상 요청이 비용을 소모하지 않는지 검사한다. 2인 Aim 프로브는 조준 0.5,0.25로 타격하고 상대 목표에 맞춰 좌우 이동하며 10개 샷의 서버 확정 Aim/Target 복제를 확인한다.

- 비교를 위해 이번에 추가했던 굵은 외곽선만 제거하고 AIM 글자 뒤의 어두운 106×22 논리 픽셀 배경을 유지했다. 최종 변경은 BadmintonHUD.cpp의 배경 패널 한 줄이다. 원과 십자선은 기존 동작을 유지한다.
- 배경만 적용한 패키지의 960×540 참가자 캡처(20260914-132102-20615)에서는 점수·역할·랠리 안내·비용·능력 상태·타격 안내·하단 조작법이 모두 표시되는 것을 직접 확인했다. AIM / CLEAR도 코트 색과 분리되어 읽힌다. 양쪽 Aim 및 같은 랠리 10회 교대 타격도 통과했다.
