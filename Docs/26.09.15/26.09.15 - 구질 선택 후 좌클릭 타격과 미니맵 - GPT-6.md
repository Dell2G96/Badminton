# 구질 선택 후 좌클릭 타격과 미니맵

## 사용자 요청
모든 기본 타격은 좌클릭으로 통일한다. Q/E/R 등으로 고른 구질에 따라 좌클릭 시 드롭·하이클리어·헤어핀 등을 친다. 오른쪽 미니맵에 내 위치, 상대 위치, 콕 위치, 콕의 예상 낙하지점을 표시한다.

## 구현과 조작
- Q 드롭 / E 하이클리어 / R 헤어핀 / Space 퀵 리시브는 구질 선택만 한다. 키를 누르는 것만으로 타격하지 않는다.
- 마지막 선택을 유지하며, 좌클릭이 선택된 구질의 실제 타격 요청을 보낸다. 기본 선택은 하이클리어다.
- 스매시는 기존 2번 준비 → 좌클릭 타이밍 방식이다. 일반 구질은 타이밍 게이지 없이 거리·높이·방향·회복·스태미나 등의 실제 접촉 조건만 판정한다.
- 서브도 좌클릭으로 친다. 다른 구질을 선택해 두었어도 서브 단계의 좌클릭은 서브다.
- 구질 키 변경은 대기 중이나 상대가 치는 중에도 가능하다. 선택은 서버에서도 보관하며 실제 일반 타격 요청은 선택된 구질과 일치해야 한다.
- 선택한 구질 카드와 중앙 설명에 현재 구질을 표시한다. 스매시가 선택되어 있고 준비되지 않은 상태에서는 2번 준비 안내를 표시한다.

## 미니맵
- 스태미나 패널 아래 오른쪽에 고정된 코트 평면도를 추가한다. 내 진영은 항상 아래, 상대 진영은 위다. 반대편 플레이어는 180도 뒤집힌 동일한 자기 기준 방향을 사용한다.
- 초록 사각형: 나, 빨간 마름모: 상대, 노란 원: 현재 콕, 하늘색 원과 X: 예상 낙하지점. 코트 밖 낙하지점은 빨간색이다.
- 콕 현재 위치는 실제 표시 중인 액터 위치를, 예상 낙하지점은 서버의 비행·네트 충돌 예측값을 그대로 사용한다. 별도의 단순 포물선 계산을 만들지 않는다.
- 콕 높이와 무관하게 XY를 평면도로 표시한다. 현재 콕과 예상 착지를 점선으로 연결한다. 랠리가 끝나거나 유효한 예측이 없으면 착지 마커를 숨긴다.
- 코트 바깥 여백까지 표시하며, 미니맵 영역을 벗어난 위치는 가장자리 방향 표시를 붙인다. 가로·세로의 실제 거리 비율은 동일하다.

## 검증 진행
에디터·게임 빌드와 BadmintonFPSStrokeMinimap 패키징 성공. 실제 키 바인딩으로 선택만 했을 때 타격이 없는지, 마지막 선택 구질로 좌클릭하는지, 타격 후 선택이 유지되는지, 중복 클릭·잘못된 조준 차단과 스매시 타이밍을 검사 중이다. 미니맵 진영 방향·현재와 예상 위치의 구분·높이 독립성 검사를 추가했다.
computer-use 없이 CLI·엔진 자동 테스트·저장 스크린샷을 사용한다. 이번 작업의 Game Bar MP4 녹화와 수동 플레이·PIE는 미수행이다.

- 에디터·게임 빌드, 쿠킹, 패키징 성공: Saved/Logs/BadmintonPackage-20260915-230127.log.

오른쪽 미니맵에 내 위치, 상대 위치, 콕 현재 위치, 예상 낙하지점을 표시한다. 수정본은 Start-BadmintonFPS.cmd로 새로 실행하면 적용된다.
