# 1인칭 및 타이밍 조작 변경

- 날짜: 2026-09-15 (Asia/Seoul), 모델: GPT-6
- 요청: 1인칭 시점, 1 드롭 / 2 스매시 / 3 하이클리어 / 4 빠른 리시브, 목표 조준 후 기술 선택, 중앙 하단 타이밍 게이지와 Space 타격, 정확도·강도 보너스, 반투명 흰색 라켓 조작, 감도 상향.
- 사용자 재개 요청에 따라 기존 오프라인 AI 경기 위에 구현한다. 멀티플레이·EOS는 후속으로 유지한다.

## 수행 내용

- 번호키로 목표를 고정하고 라켓 조작으로 전환한다. Space는 준비된 샷을 1회 타격하며 우클릭 취소, 휠 클릭 초기화.
- 기존 .004였던 목표 조준 감도를 .010으로 상향했다.
- 캐릭터 눈높이 카메라와 셔틀 추적을 적용하며 자기 몸체는 숨긴다.
- 라켓은 흰색 반투명 재질의 실제 3D 메시로 표시한다. 입력 방향과 실제 셔틀 방향이 허용 각도를 벗어나면 헛스윙.
- 타이밍을 서버 시간으로 평가하고 완벽한 타이밍에는 목표 오차를 없애고 비행 시간을 줄인다. 네트 통과 가능한 최소 궤적은 유지한다.
- 빠른 리시브는 비용 0, 후딜레이 0.18초, 도달 범위 210cm로 추가한다. 기존 GAS와 실제 거리·높이 판정을 사용한다.
- 기존 소스 해시를 확인한 후 변경했으며 최초 소스를 FPSControlWork/Before에 보관했다.

## 사용 방법

1. 프로젝트 루트 Start-BadmintonFPS.cmd 또는 Start-BadmintonAI.cmd를 실행한다.
2. Enter로 AI 대전을 시작한다.
3. 마우스로 상대 코트의 AIM 표시를 움직여 도착 지점을 정한다. WASD로 이동한다.
4. 1 드롭 / 2 스매시 / 3 하이클리어 / 4 빠른 리시브 중 선택한다.
5. LOCKED가 되면 마우스로 흰색 라켓을 셔틀콕에 맞추고, 중앙 하단 게이지의 밝은 녹색 구간에 맞춰 Space를 누른다.
6. 서브할 때는 1~4 중 어떤 번호를 눌러도 서브 준비가 되며 Space로 서브한다.
7. 우클릭은 준비 취소, 휠 클릭은 조준 초기화, Shift는 대시다. 경기 종료 후 Enter로 재경기한다.

## 구현상 범위

- 1인칭 시점이지만 마우스 자유 시점 회전은 아니다. 사용자 요청의 목표 지점 조작과 라켓 조작에 마우스를 사용하며, 준비 중 카메라는 셔틀을 추적한다.
- 반투명 라켓은 입력 가이드와 스윙 연출이다. 실제 성공은 준비한 샷, 라켓 입력 방향, 거리, 높이, 네트 통과, 비용 및 후딜레이를 공통 게임 판정으로 검사한다.
- PERFECT 구간은 이상적 타점 기준 ±45ms이며 그 밖에서는 연속적으로 품질이 줄어든다. +300ms 이후에는 준비가 만료된다.
- 강도는 같은 도착점까지의 비행 시간으로 반영한다. 네트 통과가 불가능한 너무 낮은 궤적은 보정하므로 모든 상황에서 동일한 속도 증가율을 보장하는 설계는 아니다.
- 조준 감도는 기존 대비 2.5배이며 라켓의 화면 조작 감도는 별도로 둔다.
- 새 입력 흐름의 멀티플레이 및 지연 환경은 검증 범위에서 제외했다. AI 대전을 먼저 완성한다는 사용자 결정에 따른다.
- 사람의 손맛·난이도 평가는 후속 플레이테스트가 필요하다. 기본 캐릭터 외형은 기존 원통 프로토타입이다.
