# Windows 단축키 녹화 방식 지정

## 사용자 요청
앞으로 Windows + Alt + R을 눌렀을 때 나오는 녹화 기능을 사용한다.

## 수행 내용
computer-use 스킬과 guidance.md, confirmations.md를 읽고 Windows 조작 도구를 초기화했다. 테스트용 게임을 실행하고 정확한 게임 창을 선택해 확인했다. 사용자 지시의 단축키로 녹화를 시작하려 했으나 자동 승인 검토가 이를 거절했다. Windows 키를 다른 방식으로 보내는 우회는 수행하지 않았다.

자동 검토의 거절 이유: 사용자가 녹화를 명시적으로 요청했지만 Computer Use 정책이 Windows 키 단축키(Win+Alt+R) 입력을 명시적으로 금지한다.
관련 지침: C:/Users/User/.codex/plugins/cache/openai-bundled/computer-use/26.908.70816/docs/guidance.md — “Do not use the Windows key or shortcuts involving the Windows key.”

허용 가능한 대안인 Game Bar 자체의 녹화 UI를 확인하려 했으나, sky.list_apps의 Game Bar/Xbox 검색 결과와 현재 사용자 Get-AppxPackage Microsoft.XboxGamingOverlay, Get-StartApps 검색 결과에 해당 앱이 표시되지 않았다. 따라서 현재 도구에서 직접 누를 수 있는 녹화 버튼을 확인하지 못했다. 이를 모든 사용자에 대한 미설치 증명으로 단정하지 않는다.

## 변경 파일
AGENTS.md의 단계별 시연 영상 규칙에 Windows + Alt + R을 기본 녹화 방식으로 지정하고, 실제 파일 검증 및 미시작/실패 보고 규칙을 기록했다. 이번 설명 문서도 추가했다. 게임 코드·에셋·실행 패키지는 변경하지 않았다.

## 검증 결과 및 미완료
이번 녹화는 시작하지 못했다. 새 녹화 파일을 만들었다고 주장하지 않는다. 자동 단축키 입력이 차단되어 사용자 직접 입력이 필요하며, 실제 사용자가 지정한 녹화 도구의 UI가 확인되면 그 상태를 기준으로 후속 작업한다. 사용자에게 단축키 입력을 요청한다. 기존 사용자 에디터 및 다른 앱을 종료하지 않는다.

## 최종 전달
앞으로 Windows + Alt + R 녹화를 기본 방식으로 사용하도록 기록했다. 이번 자동 입력은 승인 검토에서 차단되었으며, 사용자가 게임 창에서 직접 녹화를 시작해야 후속 저장·영상 검증을 진행할 수 있다.
