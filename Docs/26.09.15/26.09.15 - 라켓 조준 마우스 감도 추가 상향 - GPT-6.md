# 라켓 조준 마우스 감도 추가 상향

## 요청
조준하는 라켓의 마우스 감도를 더 공격적으로 높이기.

## 변경
- BadmintonPlayerController.h: MouseLookSensitivity를 0.36에서 0.72로 2배 상향했다. 마우스 입력에 대한 카메라 회전과 라켓 조준 반응에 적용된다.
- BadmintonCameraTests.cpp: 기존 검증의 감도 입력을 0.72로 맞추고 프레임 분할 비교 입력을 절반으로 줄여 회전 제한에 닿기 전의 반응을 검증하도록 유지했다.
- 실행용 BadmintonFPS 패키지를 재빌드한다.

## 검증
- 에디터와 게임 빌드 및 실행용 패키징 성공: Saved/Logs/BadmintonPackage-20260915-200043.log.
- 기존 카메라 자동 검사 2개(CourtPlacement, MouseLimits) Success: Saved/Logs/Automation-RacketSensitivity-20260915.log. 검사 시작 전 엔진 초기화 구간에 Condition failed 메시지 4건이 있었으나, 선택한 두 검사 결과는 모두 Success이며 프로세스 종료 코드는 0이다. 해당 초기화 메시지의 원인은 이번 작업에서 조사하지 않았다.
- 새 패키지 통합 검사 PASS: Saved/Logs/BadmintonTiming-20260915-200204.log. contacts=6, firstperson/aimlock/leftclick/spaceReceive/quickreceive/mouseCamera 모두 OK. 실행 중 sensitivity=0.720 적용 확인.
- git diff --check 통과. 배드민턴 소스가 기존부터 미추적 상태여서 해당 명령 외에 변경한 감도와 테스트 입력을 직접 확인했다.
- PIE 및 수동 플레이는 수행하지 않았으며 실제 패키지 자동 실행으로 조준/타격을 검증했다.

## 미완료 사항
사람의 마우스 조작감 확인 및 MP4 시연은 수행하지 않았다. 이번 변경은 감도 수치 조정이며 자동 검사로 실제 체감까지 검증할 수는 없다.

## 최종 답변
라켓 조준 감도를 현재보다 2배 높였습니다(0.36 → 0.72). 실행용 게임에 반영했고 조준·타격 자동 검사도 통과했습니다. 게임을 종료한 뒤 Start-BadmintonFPS.cmd로 다시 실행하면 적용됩니다.
