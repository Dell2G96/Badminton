# 스페이스바 즉시 퀵 리시브

## 요청
마우스로 조준한 뒤 스페이스바 한 번으로 퀵 리시브를 즉시 타격한다. 타이밍 게이지나 추가 좌클릭 없이 동작한다.

## 변경
- 기존 BadmintonSelectReceive 입력 함수가 서버의 단일 즉시 리시브 요청을 호출한다. 서버에서 타격 문맥을 구성하고 같은 요청 안에서 기존 GAS·타격 판정을 실행한다.
- 다른 샷을 준비 중이어도 스페이스바가 준비를 취소하고 현재 마우스 방향으로 퀵 리시브한다. 서버에서 타이밍 UI 활성화 응답을 보내지 않는다.
- 타이밍 점수와 무관하게 기존 안정적인 리턴 품질 0.65, 완화된 조준 허용각 20도, 중앙 위주 방어 리턴을 유지한다.
- 샷을 선택하지 않아도 랠리 중 라켓과 타격 가능 색상을 표시한다. HUD 안내를 SPACE TO HIT로 바꾼다.
- 실제 거리·높이·자기 진영·네트 통과·동작 회복 및 중복 타격 판정은 유지한다. 범위 밖에서 누르면 예약 타격하지 않고 실패 안내한다.
- 서브는 1~3 선택 후 좌클릭 방식이다. 스페이스바가 서브로 변환되지 않도록 한다.

## 검증
빌드 및 BadmintonFPSInstantReceive 패키징 진행 중.
기존 게임 입력 바인딩을 호출하는 자동 테스트를 갱신해, 선택 없이 스페이스바 한 번으로 즉시 타격, 기존 샷 덮어쓰기, 잘못된 조준 실패, 반복 스페이스바·추가 클릭의 중복 방지, 타이밍 독립성과 연습 이벤트를 확인한다. 1~3 샷의 타이밍·좌클릭 검증도 유지한다.
computer-use 없이 CLI·엔진 자동 테스트와 저장 화면을 사용한다. 이번 작업의 실제 Game Bar 녹화, 사람의 직접 플레이 및 PIE는 아직 수행하지 않았다.

- 별도 에디터 런타임 검사는 셔틀콕 정적 메시 준비 단계에서 대기하여 자체 검사 프로세스만 종료했다. 해당 검사는 성공으로 집계하지 않는다. 로그: Saved/Logs/BadmintonTiming-20260915-220759.log. 에디터 빌드는 성공했지만 PIE·사람의 직접 플레이와 Game Bar 영상은 미검증이다.
- Start-BadmintonAI.cmd가 BadmintonFPSInstantReceive 패키지를 실행하도록 갱신. Start-BadmintonFPS.cmd도 같은 최신 버전을 실행한다. 이전 패키지와 사용자 실행 프로세스는 보존했다.

## 사용자 안내
마우스로 셔틀콕을 조준하고 스페이스바를 한 번 누르면 즉시 퀵 리시브한다. 타이밍 게이지와 추가 좌클릭은 필요 없다. 타격 범위와 조준이 맞으면 초록색 라켓으로 알려준다. 1~3번 샷은 기존 좌클릭 타이밍 방식이다. 수정본은 Start-BadmintonFPS.cmd로 새로 실행하면 적용된다.
