# 실제 낙하지점 표시 수정

## 요청과 원인
셔틀콕의 낙하 착지 지점이 정확하지 않다는 사용자 피드백.
기존 HUD에는 조준 목표(AIM/LOCKED)와 연습 목표(LAND HERE)만 있었고 실제 비행의 낙하지점 표시는 없었다. 특히 조준 목표는 샷 종류에 따라 공중 높이를 가질 수 있고, 타이밍 오차와 네트 충돌도 최종 착지를 바꾸므로 이를 바닥에 투영한 위치는 실제 착지와 다르다.

## 구현
- 서버가 샷 발사 직후 실제 발사 속도로 비행을 예측한다. 실제와 동일한 중력, 공기저항, 1/120초 간격, 반경 5cm 구체, WorldStatic 충돌 응답을 사용한다.
- 네트 충돌 후 감속과 하강, 유효 네트 통과 및 경기 종료 조건을 반영한다. 실제 네트 충돌 발생 시 다시 계산해 상태를 갱신한다.
- 예측 위치를 비행 상태에 포함한다. 화면 보간 위치와 발사 순간 속도를 섞어 계산하지 않는다.
- 하늘색 원과 중심 십자로 LANDING 표시. 코트 외부는 빨간 LANDING / OUT. 조준은 AIM / AIM LOCKED, 연습 목표는 CHALLENGE로 구분한다.
- 상대가 받아치면 새 샷의 위치로 바뀌며, 랠리 종료·서브 리셋 시 표시를 지운다. 아무도 추가 타격하지 않았을 때의 예상 착지다.
- 바닥 밖이나 네트 통과 규칙 위반으로 공중에서 경기가 종료되어 실제 바닥 접촉이 없으면 허위 착지점을 만들지 않는다.

## 검증 계획과 현재 상태
빌드·패키징 진행 중. 실제 액터의 이동 충돌을 기준으로 30/60/144fps, 양쪽 코트, 일반 비행·드롭·공중 목표·네트 충돌·아웃의 예측 오차를 검사한다. AI 게임에서도 실제 착지와 표시 위치 오차가 2cm 미만인지 확인한다.
computer-use를 사용하지 않고 CLI와 엔진 테스트로 진행한다. 이번 작업의 Game Bar 녹화와 사람의 직접 플레이·PIE 검증은 수행하지 않았다.

## 최종 안내
실제 비행·충돌로 계산한 하늘색 LANDING이 예상 착지점이다. 코트 밖은 빨간색으로 표시하고 네트에 맞거나 상대가 받아치면 갱신한다. 조준점과 연습 목표는 별도로 구분한다. 수정본은 Start-BadmintonFPS.cmd로 새로 실행하면 적용된다. 테스트상 정확도는 위 조건에서 확인한 수치이며 향후 다른 타격이 들어오면 예상 위치도 바뀐다.
