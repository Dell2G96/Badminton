# 프로젝트 고품질 셔틀콕과 네트 적용

## 요청 및 조사
- 사용자 요청: 셔틀콕과 네트 모두 프로젝트 내부의 다른 고품질 에셋으로 교체.
- 기존 셔틀콕은 엔진 Sphere, 네트는 Cube 패널과 막대 조합이었음.
- 셔틀콕 원본: /Game/Badminton/Models/Shuttle/SM_Badminton_Shuttle_Source. 깃털/코르크 메시와 diffuse/normal 재질 보유. 약 50만 삼각형.
- 코트 원본 SM_Badminton_Court_Source는 조사 시 네트 면/지주 형상이 불완전함. 프로젝트의 /Game/Badminton/Prototype/SM_SM_Badminton_Court_Details에는 실제 망·테이프·지주 구조와 3개 재질이 있으므로 이를 선택.
- 기존 원본은 보존하고 /Game/Badminton/Models/Gameplay에 게임용 사본 생성. 네트의 코트 바닥 라인은 분리 제거.

## 구현
- 셔틀콕: SM_Badminton_Shuttle로 교체. 표시 크기 약 13.8cm. 코르크 중심을 기존 충돌체 중심에 맞추고 비행 방향에 따라 코르크가 앞으로 향하도록 메시만 회전.
- 원본 텍스처 보존. 거리별 LOD를 생성하여 먼 거리 비용 감소.
- 네트: SM_Badminton_Net. 기존 디테일 에셋에서 네트 주변만 추출하고 기존 코트 축/155cm 높이에 맞춤.
- 타격, 비행, 스코어와 충돌 규칙은 보존. 기존 지주 충돌은 숨긴 메시로 유지하고 상세 네트는 시각 표현만 사용.
- 기존 타격 통합 검사에 패키지의 실제 메시 참조 확인을 추가.

## 에셋 준비 완료
- 셔틀콕: 기존 diffuse/normal 재질을 그대로 사용하는 SM_Badminton_Shuttle 사본에 LOD 3단계 생성 완료. 원본은 보존.
- 네트: SM_Badminton_Net_Detailed 저장 성공. 중앙 (0,0), 높이 155cm, 지주 받침 포함 폭 652cm, 4560개 삼각형. 원본 Court_Details에서 바닥 라인 576개 삼각형 제거.
- Python Rotator는 명명 인수(yaw=90)를 사용해 코트 축을 정확히 맞춤. 선택 영역의 역전 방식도 삼각형 선택 자체를 뒤집도록 수정.
- 첫 네트 파일에 저장 충돌이 발생하여 보정된 네트는 별도 이름 SM_Badminton_Net_Detailed로 저장하고 런타임 참조 변경. 초기 SM_Badminton_Net은 사용하지 않음.
- 최종 에셋 준비 로그: Saved/Logs/PrepareVisualAssets-Detailed-20260915.log. 메시 저장 성공 여부를 명시적으로 확인하도록 스크립트 보강.
- 기존 155cm 네트/지주 충돌 및 5cm 셔틀콕 충돌 구는 그대로이며 메시만 교체·회전.
