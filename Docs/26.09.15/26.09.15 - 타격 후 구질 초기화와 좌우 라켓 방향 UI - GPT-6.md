# 타격 후 구질 초기화와 좌우 라켓 방향 UI

**최종 상태: 사용자 승인에 따라 기본 배드민턴 캐릭터를 복구하고, 구질 초기화·좌우 휠·예상 방향 UI를 적용한 패키지 검증 및 런처 연결 완료.**

## 사용자 요청

1. 한 번 스트로크를 치면 이전 선택 구질을 기억하지 않고 초기화한다.
2. 휠 각도는 상하 기울기가 아니라 좌우 발사 방향 조절로 수정하며 예상 방향을 UI로 보여준다.
3. 앞선 라켓 투명도 개선은 함께 유지한다.

## 동작 결정

- 성공한 타격 직후 기본 퀵 리시브로 초기화한다. Q 드롭 / E 하이클리어 / R 헤어핀 / 2 스매시는 사용할 때마다 다시 선택한다.
- 아무 구질 키도 누르지 않고 좌클릭하면 기본 리시브다. 서브 상황에서는 좌클릭으로 서브한다.
- 헛스윙이나 타격 거절은 선택 구질을 소비하지 않는다.
- 휠 위 = 오른쪽, 휠 아래 = 왼쪽, 한 칸 3도, 범위 ±30도. 가운데 버튼은 시점과 면 각도를 초기화한다.
- 구질 초기화는 라켓 휠 각도를 초기화하지 않는다.
- 스매시는 기존 타이밍과 고정 면 방향을 유지하며 휠 영향에서 제외한다.

## 구현

### 좌우 반사

BadmintonRacketPhysics의 면 회전축을 월드 상방 축으로 바꿨다. 같은 좌우 회전을 화면 라켓 메시와 실제 반사 물리에 적용한다. 양쪽 코트에서 양의 각도는 각 플레이어 기준 오른쪽이다. 들어오는 콕의 속도와 움직이는 라켓 면의 상대 속도, 기존 반발·마찰 계산은 유지한다. 타격 뒤의 실제 궤적, 바닥 착지점과 미니맵 착지점이 영향을 받는다.

### 예상 방향

왼쪽 연습 패널 아래 EXPECTED DIRECTION 패널을 추가했다. 화살표는 코트를 위에서 본 수평 발사 방향이며 위가 상대 진영, L/R이 내 기준 좌우다. OUT 값은 정면 대비 예상 발사각이다. FACE L/R 값은 라켓 면 각도이므로 두 숫자는 다를 수 있다.

구질의 기본 궤적과 네트 여유 높이를 결정하는 계산을 BadmintonPlayerFlight.h로 추출했다. 실제 서버 타격과 UI 미리보기가 이를 공유하며 같은 반사 함수도 호출한다. UI는 매번 최신 카메라 조준과 현재 셔틀 속도를 사용한다.

IF HIT NOW는 현재 위치·속도에서 즉시 쳤을 때의 방향을 의미한다. 콕이 움직이면 예상 방향도 바뀐다. 미래 타격시점이나 최종 착지를 확정하는 표시는 아니다. 본인 타격 뒤에는 다음 콕을 기다리는 안내를 표시하며 스매시 중에는 고정 면 안내를 표시한다.

### 구질 초기화

서버가 실제 샷 시퀀스 증가로 타격 성공을 확인한 뒤 선택 구질을 Receive로 복구한다. 클라이언트에도 복구를 알리고 타이밍 준비 상태를 해제한다. 실패 경로는 선택 상태를 유지한다. 기본 시작 구질도 Receive다.
