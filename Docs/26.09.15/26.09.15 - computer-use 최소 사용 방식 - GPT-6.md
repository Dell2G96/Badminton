# computer-use 최소 사용 방식

## 사용자 요청
computer-use가 필수인지 확인하고 최대한 사용하지 않는 방식으로 진행한다.

## 결정
computer-use는 모든 작업에 필수인 도구가 아니다. 이 프로젝트의 코드 변경, 빌드, 패키징, 자동 게임 테스트, 로그 확인, 영상 파일 검증은 명령어와 스크립트로 진행할 수 있으며 실제로 앞선 검증에서도 사용했다.
앞으로는 CLI, 기존 스크립트, 전용 API를 먼저 사용한다. 화면 클릭이 불가피한 경우에만 computer-use를 검토한다.
Windows + Alt + R 녹화는 사용자가 단축키로 시작/종료하고, 에이전트는 테스트 실행과 저장 파일 검증을 담당한다. 이전 자동 승인 검토가 거절한 Windows 키 입력을 다른 방식으로 우회하지 않는다.

## 수행 내용 및 변경 파일
AGENTS.md의 빌드/테스트 작업 지침에 사용자 선호를 기록했다. 이 문서를 추가했다. 게임 코드와 패키지는 변경하지 않았다.

## 검증 및 미완료
문서 기록과 지침 반영만 수행했다. 이번 턴에 computer-use 호출, 새 테스트 실행, 녹화 시작/종료, 게임 프로세스 재시작은 수행하지 않았다. 사용자로부터 이전 녹화 시작 알림은 받았지만 정상 영상 저장 여부는 아직 검증하지 않았다.

## 최종 답변
필수는 아니다. 앞으로 코드 수정·빌드·게임 자동 테스트·로그/영상 검증은 명령어와 스크립트를 우선 사용한다. 녹화는 사용자가 Win+Alt+R로 시작/종료하고 저장된 영상은 에이전트가 확인한다. 실제 화면 조작이 꼭 필요한 경우에만 computer-use를 사용한다.
