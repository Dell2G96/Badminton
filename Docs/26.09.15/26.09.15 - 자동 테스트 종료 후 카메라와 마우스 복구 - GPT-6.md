# 자동 테스트 종료 후 카메라와 마우스 복구

## 요청
카메라가 계속 하늘을 보는 원인 확인 및 수정.

## 원인
현재 실행 중인 PID 33868은 녹화 준비 때 에이전트가 실행한 BadmintonTimingTest 프로세스다. 시작 옵션에는 slomo 0.4가 포함되어 있다. Saved/Logs/GameBarRecording-20260915-212840.log에 21:29:40 테스트 PASS가 기록되었지만, bTimingProbe 플래그가 남은 상태에서 UpdateMouseAim이 계속 사용자 마우스 입력을 무시했다. 자동 조준 마지막 각도가 유지되었고 21:33 로그의 pitch는 48.961도였다. 일반 플레이 모드의 자동 추적 설정 때문이 아니라, 자동 테스트 종료 후 제어를 복구하지 못한 버그다.

## 수정
- BadmintonPlayerController.h/.cpp: 자동 타이밍 테스트 실행 중 여부를 성공/실패 완료 상태와 함께 판단한다. 종료 후에는 수동 마우스 입력을 허용하고, 카메라를 yaw 0 / pitch -12로 복원한다. 자동 스윙과 남은 이동 입력을 비우고 게임 속도를 1배로 되돌린다. 기존 테스트 플래그 자체는 보존해 테스트가 사용자 설정 파일을 덮어쓰지 않게 한다.
- BadmintonHUD.cpp: 자동 테스트 중에는 AUTO TEST / CAMERA CONTROLLED를 표시해 일반 플레이와 구분한다.
- Scripts/Test-BadmintonTiming.ps1: 기존 타격 PASS뿐 아니라 마우스·카메라·속도 복구 로그까지 확인한 후 검사를 종료한다.
- Scripts/Test-BadmintonCameraHandoff.ps1: 의도적인 개발용 테스트 중단을 주입하여 실패 시에도 동일한 복구가 수행되는지 확인한다.

## 빌드와 실행 보존
현재 사용자가 녹화 중일 수 있는 게임과 에디터를 종료하거나 재시작하지 않았다. 실행 중인 기존 패키지를 덮어쓰지 않기 위해 수정본은 Saved/Packages/BadmintonFPSCameraFix/Windows에 별도로 생성한다. 검증이 완료되면 기존 바로가기가 이 수정본의 일반 플레이를 실행하도록 변경한다.

## 검증 진행
1차 빌드에서 상위 클래스 Character 멤버와 지역 변수의 이름 충돌(C4458)을 발견하여 ControlledPlayer로 변경했다. 수정 빌드 로그는 Saved/Logs/BadmintonPackage-20260915-213915.log다. 최종 성공/실패 종료 복구 검사는 이어서 기록한다.

## 사용자 안내
현재 실행 중인 이전 버전은 마우스 휠 클릭으로 카메라를 정면으로 돌릴 수 있다. 마우스 자유 조작까지 복구하려면 녹화를 끝내고 기존 게임을 닫은 뒤 수정본을 일반 모드로 실행해야 한다.

## 변경 보존 및 미완료
원본은 Docs/26.09.15/CameraHandoffWork/Before에 보관했다. 이번 작업에서 computer-use나 녹화 단축키 입력은 사용하지 않았다. 새 녹화 영상과 사람의 수동 조작은 아직 검증하지 않았다. 기존 녹화 저장 여부는 이 수정 작업에서 확인하지 않았다.

## 최종 검증 및 전달
- 에디터/게임 빌드, 쿠킹, 패키징 성공: Saved/Logs/BadmintonPackage-20260915-213915.log.
- 실제 수정 패키지에서 모든 샷 접촉 검사와 정상 테스트 종료 후 제어 복구 PASS: Saved/Logs/BadmintonTiming-20260915-214144.log. contacts=6, manualMouse=enabled, look=X=0.000 Y=-12.000, timeDilation=1 확인.
- 강제 중단 경로에서도 동일한 제어 복구 PASS: Saved/Logs/CameraHandoffFailure-20260915-214146.log. 해당 로그의 requested abort 오류는 검사에서 의도적으로 주입한 중단이며, 그 뒤 복구가 성공한 것을 확인했다.
- PowerShell 검사 스크립트 구문 확인과 git diff --check 통과.
- Start-BadmintonAI.cmd를 수정해 Start-BadmintonFPS.cmd가 새 BadmintonFPSCameraFix 패키지의 일반 플레이를 실행하도록 연결했다. 자동 테스트 옵션과 slomo 옵션은 일반 실행 바로가기에 없다. 이전 설정 파일이 존재하고 새 파일이 없을 때는 그대로 복사하도록 처리했다.
- 현재 녹화용 PID 33868과 기존 에디터는 종료하지 않았다. 실행 중인 이전 프로그램의 메모리에 이번 수정이 즉시 적용되는 것은 아니다.

## 최종 답변
에이전트가 실행한 녹화용 자동 테스트가 끝난 뒤에도 마우스 입력 차단과 위쪽 카메라 각도가 남아 발생했다. 테스트가 끝나면 정면 시점, 수동 조작, 정상 속도로 복구하도록 수정했고 성공/실패 두 경로를 실행 패키지에서 확인했다. 현재 창에서는 휠 클릭으로 정면 복귀가 가능하며, 녹화를 종료하고 기존 게임을 닫은 뒤 Start-BadmintonFPS.cmd로 다시 실행하면 수정본을 사용할 수 있다.
