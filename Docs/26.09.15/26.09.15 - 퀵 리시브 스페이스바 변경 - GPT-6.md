# 퀵 리시브 스페이스바 변경

## 요청과 수행
- 사용자 요청: 퀵 리시브를 스페이스바로 키 변경.
- 퀵 리시브 선택 키를 4에서 Space로 이동. 좌클릭 타격과 타이밍 없는 리시브 동작은 유지.
- 서브 안내, 선택 전 안내, 기술 카드와 하단 조작법을 1/2/3/SPACE 기준으로 변경.
- 기존 타격 통합 검사를 새 Space 입력 바인딩으로 리시브를 선택하도록 갱신. 실제 좌클릭 바인딩으로 타격 검증을 이어감.
- 변경 파일: BadmintonPlayerController.cpp, BadmintonHUD.cpp. 변경 전 사본: SpaceReceiveWork/Before.
- 기존 사용자 변경과 실행 중인 에디터를 보존. 커밋/PR 없음.

## 검증
- 기존 바로가기용 Windows 패키지 빌드 및 렌더러 통합 검사 진행 중.
- 실제 PIE/MP4 시연은 미검증. 앞서 반디캠 FPS 표시로 사용자가 불편을 겪어 이번에는 녹화 프로그램을 실행하지 않음. 기존 렌더러 통합 검사 화면으로 UI 확인 예정.

## 조작
- Space: 퀵 리시브 선택.
- 마우스: 흰 라켓을 셔틀콕에 정렬.
- 좌클릭: 타이밍 없이 적당한 강도로 리턴.
- 1 드롭 / 2 스매시 / 3 하이클리어는 기존대로 선택 후 타이밍에 맞춰 좌클릭.
- [게임 실행](D:/_Projects/FPS_Dell2g/Start-BadmintonFPS.cmd).
