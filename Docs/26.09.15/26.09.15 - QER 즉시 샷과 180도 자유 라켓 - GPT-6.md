# QER 즉시 샷과 180도 자유 라켓

## 사용자 요청과 조작 결정
- Q: 드롭 즉시 타격, E: 하이클리어 즉시 타격, R: 헤어핀 즉시 타격.
- 스매시만 타이밍 입력을 유지한다. 기존 2번 선택 → 좌클릭 방식 사용.
- 스페이스바 즉시 퀵 리시브는 유지한다. 서브는 E 한 번으로 실행한다.
- 라켓이 중앙에 고정되지 않고 좌우·위로 뻗으며 180도 범위에서 회전한다.

## 구현
- 헤어핀 enum·GAS 이벤트·능력·샷 파라미터·능력 부여를 추가했다. 헤어핀 목표는 네트 너머 65~135cm, 드롭은 160~285cm로 구분한다.
- Q/E/R/Space는 같은 단일 서버 요청에서 타격한다. 스매시 준비를 덮어쓸 수 있고, 스매시만 타이밍 점수·오차·파워를 반영한다. 즉시 샷은 고정 품질을 사용한다.
- 좌우 조준은 -90~+90도, 상하는 -45~+85도. 카메라가 조준 방향을 일정 범위 내에서 덜 따라가 라켓 머리가 중앙에서 좌우·위로 이동한다. 좌우 자세에 따라 손잡이 회전은 -90~+90도로 총 180도다.
- 실제 타격 방향과 라켓 머리 방향은 같은 값을 사용한다. 화면 조준점도 라켓 중심을 따라간다. 카메라가 보는 중앙에 고정된 타격 판정은 사용하지 않는다.
- 즉시 샷의 조준 허용각은 20도, 스매시는 기존 12도. 실제 거리·높이·차례·회복·스태미나·중복 타격 검증을 유지한다.
- HUD를 5개 기술 카드로 갱신하고, 타이밍 게이지는 스매시 준비 시에만 표시한다.

## 파일과 백업
변경 파일은 Source/FPS_Dell2g/Badminton의 Types, ShotData, ClearAbility, Character, Timing, Camera, PlayerController, PlayerExperience, GameMode, PlayFeel, HUD와 Tests의 CameraTests/FreeRacketTests다.
수정 전 백업은 Docs/26.09.15/FreeRacketWork/Before에 보관한다.

## 검증 상태
에디터·게임 빌드 통과 후 패키징 진행 중. 새 입력 바인딩으로 헤어핀까지 실제 타격하는 검사, 샷 거리 구분, 180도 라켓·조준 일치·화면 내 위치의 자동화 검사를 준비했다. computer-use 없이 CLI와 저장 화면으로 확인한다. 실제 Game Bar 녹화·사람의 직접 플레이 및 PIE는 이번 작업에서 미수행이다.

## 최종 검증과 수정
- 전체 배드민턴 자동화 테스트 22개 성공: Saved/Logs/Automation-FreeRacket-20260915.log.
- 실제 패키지 입력 검사 성공: Saved/Logs/BadmintonTiming-20260915-223421.log. mask=63, 실제 타격 8회, Q/E/R/Space 즉시 타격, 스매시 타이밍과 조준 잠금, 중복 입력 차단, 헤어핀 목표 65~135cm, 타격 연습 이벤트와 카메라 수동 복구 확인.
- 첫 자세 화면 확인에서 서브 대기 중 라켓 숨김을 발견했다. 서브 대기에서도 라켓을 표시하도록 수정하고, 자동 검사가 실제 가시성까지 확인하도록 강화했다.
- 좌우로 뻗을 때 손잡이가 몸 쪽을 향하도록 회전 방향을 다듬었다. 드롭·헤어핀 AIM 표시도 InstantPlacementTarget을 공유해 샷별 거리와 맞췄다.
- 최종 빌드/쿠킹/패키징 성공: Saved/Logs/BadmintonPackage-20260915-223820.log. 최종 패키지: Saved/Packages/BadmintonFPSFreeRacket/Windows.
- 최종 카메라/라켓/헤어핀 자동화 테스트 3개 성공: Saved/Logs/Automation-FreeRacket-Final-20260915.log. 테스트 실행 전 기존 엔진 초기화의 Condition failed 4줄은 존재하지만 선택한 테스트는 모두 Success, 종료 코드 0이다.
- 최종 렌더링 자세 검사 및 제어 복구 통과: Saved/Logs/RacketPose-20260915-223939.log. 저장된 왼쪽·머리 위·오른쪽 화면을 직접 확인했다. 라켓의 머리 위치가 조준 광선과 일치하고, 라켓은 실제로 보이며 손잡이는 몸 쪽으로 기울어진다.
- Start-BadmintonAI.cmd를 새 패키지로 갱신했다. Start-BadmintonFPS.cmd도 이를 통해 최신 일반 모드로 실행한다. 이전 패키지와 사용자 실행 중 프로세스는 보존했다.
- 신규 Scripts/Test-BadmintonRacketPose.ps1은 화면 외 렌더링으로 3개 자세를 저장하고 정상 제어 복구를 검사한다. 해당 스크립트가 생성한 프로세스만 종료한다.
- 이번 검증은 CLI·엔진 자동 테스트·저장 스크린샷으로 수행했다. computer-use, Windows 키 입력, 다른 녹화 프로그램을 사용하지 않았다. 실제 Game Bar MP4 녹화, 사람의 직접 플레이와 PIE는 미수행이다.

## 최종 사용자 안내
| 입력 | 동작 |
|---|---|
| Q | 드롭 즉시 타격 |
| E | 하이클리어 즉시 타격, 서브 대기 중에는 서브 |
| R | 헤어핀 즉시 타격 |
| Space | 퀵 리시브 즉시 타격 |
| 2 → 좌클릭 | 스매시 선택 후 타이밍 타격 |

라켓은 화면 중앙에서 좌우·위로 뻗고 좌우 180도 범위로 조준·회전한다. 움직인 라켓 중심과 실제 타격 판정 방향을 일치시켰다. 마우스 가운데 버튼으로 정면 복귀한다. 수정본은 Start-BadmintonFPS.cmd로 새로 실행하면 적용된다.
