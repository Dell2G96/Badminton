# 게임 UI 전체 한국어화

- 작업일: 26.09.21 Asia/Seoul. 모델: GPT-6.
- 요청: 모든 UI 언어를 한국어로 수정.
- 시작 시 git status와 최근 이력을 확인했다. 기존 사용자 변경과 실행 중인 게임을 보존한다.

## 범위와 수행 내용

- 현재 3인칭과 보존된 1인칭·분할 HUD, 조작 안내, 타격·득점·승패, 연습 과제, 감도·난이도 알림, 온라인 로그인·방 검색·참가·연결 오류 안내를 한국어화한다.
- 키 이름(Q/E/R/Space/Enter 등), 기술 식별자, 프로토콜, 테스트 마커와 파일명은 유지한다. 사용자 작성 방 이름은 원문 그대로 표시한다.
- UE 엔진 소스에서 기본 한국어 나눔고딕 대체 글꼴은 에디터 전용임을 확인했다. 패키지에서 운영체제/에디터 글꼴에 의존하지 않도록 나눔고딕 원본과 SIL Open Font License를 프로젝트 콘텐츠에 포함한다.
- 글꼴은 원본 수정 없이 복사하며 글꼴 라이선스는 패키지의 별도 읽을 수 있는 파일로 동봉한다.
- 안내 문구만 번역하고 기존 게임 규칙과 입력·타격 방식은 유지한다.

## 변경 파일

- HUD/안내: `BadmintonHUD.h/.cpp`, `BadmintonThirdPersonHUD.cpp`, `BadmintonDualViewHUD.cpp`.
- 샷/판정/연습: `BadmintonTiming.h`, `BadmintonPlayFeel.cpp`, `BadmintonPlayerController.cpp`, `BadmintonThirdPersonController.cpp`, `BadmintonPlayerExperience.cpp`, `BadmintonGameMode.cpp`.
- 온라인 안내: `BadmintonOnlineSubsystem.h/.cpp`.
- 위 소스는 모두 `Source/FPS_Dell2g/Badminton/` 아래에 있다.
- 글꼴: `Content/Badminton/UI/Fonts/NanumGothic.ttf`, `Content/Badminton/UI/Licenses/NanumGothic_License.txt`.
- 패키지·모듈: `Config/DefaultGame.ini`, `Source/FPS_Dell2g/FPS_Dell2g.Build.cs`. SlateCore와 글꼴 UFS/라이선스 NonUFS 포함, 표시용 창 제목 배드민턴 추가. 프로젝트/모듈 식별자는 유지한다.
- 실행 메뉴: `Start-BadmintonAI.cmd`, `Start-BadmintonDualView.cmd`, `Start-BadmintonPackage.cmd`, `Start-BadmintonEOS.cmd`, `Scripts/Start-BadmintonPackage.ps1`, `Scripts/Start-BadmintonEOS.ps1`.
- `Start-BadmintonThirdPerson.cmd`는 기존 AI 실행 메뉴를 호출하므로 수정 없이 새 한국어 패키지로 연결된다.

## 검증 계획

에디터 빌드, PIE, 패키지 실제 렌더 이미지에서 한글 표시와 잘림을 확인한다. 영어 사용자 안내 잔여 항목을 소스에서 재검색한다. 키·물리 입력 검사는 기존 실제 플레이 프로브로 확인한다.

## 미완료 및 제한

온라인 메시지 번역은 실제 EOS 인증/외부망 성공을 의미하지 않는다. Windows + Alt + R 수동 녹화는 별도다.

### 진행 1

- 사용자 화면·알림의 155개 소스 줄을 한국어화했다. 사용자에게 보이는 문구 경로를 재검색했으며 키 이름/형식 지정자를 제외한 영어 안내 잔여 항목은 발견하지 않았다.
- 에디터 빌드 성공: `Build-KoreanUI.log`.
- 실제 PIE 검사 성공: `BadmintonDualViewPIE-20260921-105901.log`. 저장된 PIE 화면에서 한국어 HUD 표시를 확인했다.
- HUD 측정·렌더링 모두 프로젝트에 포함한 동일 나눔고딕 UFont를 사용한다. 기본 폰트 크기는 13이고 기존 최대 폭 맞춤 축소를 유지한다.
- 실행 메뉴와 온라인 런처의 사용자 안내도 한국어화했다. CMD에는 UTF-8 코드 페이지를 지정했다. 기본 실행/온라인/비교용 분할 화면 메뉴를 새 한국어 패키지로 연결한다.
- BadmintonKoreanUI 별도 패키지를 생성 중이다. 실행 중인 이전 패키지는 중단하지 않는다.

### 진행 2

- 패키지 3인칭 실제 렌더 검사 통과: `BadmintonThirdPerson-20260921-110143.log`. 모든 5종 입력·타격 통과(mask=62, keyboardShots=1).
- 패키지 분할/1인칭 전환 검사 통과: `BadmintonDualView-20260921-110144.log`. 3개 모드의 PNG를 직접 확인했으며 한글 글자와 안내가 깨지거나 패널 밖으로 잘리지 않았다.
- 독립적인 광범위 잔여 문자열 검색에서 타격 피드백 CONNECTED/NO CONTACT와 기본 컴퓨터 상대 이름을 추가 발견해 타격 성공/헛스윙, 연습 상대로 번역했다. 최종 재빌드·패키징에 포함한다.
- 실제 패키지의 `FPS_Dell2g/Content/Badminton/UI/Licenses/NanumGothic_License.txt` 동봉을 확인했다. 폰트 파일을 패키지에서 직접 불러와 한글을 렌더링하는 것도 실제 화면으로 확인했다.

## 검증 범위와 제한

- 게임 화면은 패키지의 실제 렌더 결과를 확인했다. 문구를 이미지로 덧씌우지 않았다.
- 최종 소스는 영어 사용자 안내 잔여 항목을 다시 검색했다. 로그/테스트 식별자, 키 이름, 기술 파일명, 사용자 입력 방 이름은 번역 대상으로 바꾸지 않는다.
- 별도 PC/LAN, 지연/손실 조합, 실제 EOS 로그인·외부망은 이번 UI 변경에서 재검사하지 않았다. 외부 에픽 로그인 브라우저의 자체 UI 언어는 게임 소스가 제어하지 않는다.
- 5종 키 입력 타격과 화면 전환을 검사했다. 모든 경기 상태를 각각 화면 캡처하거나 전체 경기까지 다시 진행한 검사는 아니다.
- MP4 시연 녹화는 미완료다. Windows + Alt + R 녹화 시작/종료는 사용자 수동 입력 방식으로 진행한다.
- 커밋·PR은 만들지 않았다. 기존 실행 패키지와 사용자 변경은 보존했다.

## 사용자 전달 요약

게임 HUD·조작 안내·타격 판정·득점/승패·연습 알림·온라인 접속 안내와 실행 메뉴를 한국어로 통일했다. 한글 글꼴도 패키지에 포함했다. 3인칭·1인칭·분할 화면의 한글 표시와 5종 타격 검사를 통과했다. 키 이름과 파일명은 식별을 위해 유지하며 새 한국어 패키지를 실행 메뉴로 제공한다.
