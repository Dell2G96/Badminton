- 요청: 현재 게임이 데디케이티드 서버 기반인지 리슨 서버 기반인지 확인한다.

## 결론 및 최종 답변

현재 멀티플레이는 **리슨 서버(Listen Server) 기반**이다.

- 방을 만든 플레이어의 PC가 서버와 플레이어 역할을 동시에 수행한다.
- 상대 플레이어는 해당 호스트에 접속하며, 셔틀콕 물리·타격·득점 판정은 호스트의 서버 로직에서 확정한다.
- EOS 연결도 현재 리슨 서버 방식으로 구성되어 있다. EOS를 사용한다고 별도 전용 게임 서버가 생기는 것은 아니다. 실제 EOS 계정·외부망 검증은 아직 남아 있다.
- 호스트 게임 프로세스가 종료되면 해당 경기를 계속 유지할 서버가 없어진다.

데디케이티드 서버는 현재 구성되어 있지 않다. 전환하려면 서버 빌드 대상, 별도 서버 실행·배포와 접속 구조, 전용 서버 환경의 경기·GAS·복제 검증이 추가로 필요하다. 이번 질문은 구조 확인이므로 전환 작업은 시작하지 않았다.
