# 드롭과 헤어핀 위치 자동 통합

- 작업일: 26.09.21 Asia/Seoul. 모델: GPT-6.
- 요청: 헤어핀을 드롭에 통합하고 전위에서는 헤어핀, 후위에서는 드롭으로 자동 발사.
- 시작 시 git status와 최근 이력을 확인하고 기존 미커밋 변경을 보존했다.

## 설계 및 진행

- 현재 기본인 3인칭 플레이에서 Q 하나로 통합한다. 기존 R 입력도 같은 통합 동작으로 연결한다. 비교용 1인칭 입력은 보존한다.
- 전위는 네트부터 짧은 서비스 라인(네트에서 198cm)까지, 그 뒤는 후위로 정의한다. 선 위는 전위다. 양 진영의 좌표를 반영한다.
- 타격 순간 서버의 캐릭터 위치로 최종 샷을 결정한다. 클라이언트가 헤어핀이라고 요청해도 후위에서 강제로 사용할 수 없다.
- 선택 상태는 드롭 계열 하나로 유지하고 화면·목표·타이밍 높이는 위치에 따라 갱신한다. GAS 발동 전에 실제 샷을 결정하여 헤어핀/드롭의 기존 스태미나 비용과 회복 시간도 함께 적용한다.
- HUD에서 별도 R 헤어핀 안내를 제거하고 현재 Q가 전위 헤어핀/후위 드롭 중 무엇인지 표시한다.
- 자동 플레이 검사는 드롭과 헤어핀 모두 Q 처리 함수를 호출하고 실제 이동으로 전위/후위를 맞추도록 갱신한다.

- `Start-BadmintonThirdPerson.cmd` / `Start-BadmintonAI.cmd`: 최종 `Saved/Packages/BadmintonAutoDrop/Windows/` 패키지 실행.

## 제한 및 사용자 전달

실제 사람의 조작감 평가와 수동 MP4 녹화는 별도다. 이번 작업에서 EOS 인증/외부망과 별도 PC/LAN, 전체 지연·손실 조합, 장시간 경기까지 검증한 것은 아니다. 기존 실패한 AI 검사와 보완 후 성공을 위 기록에서 구분했다. 커밋·PR은 만들지 않았다.

사용자 전달: Q 하나로 통합했다. 전위에서는 헤어핀, 후위에서는 드롭이 자동으로 나가며 화면 안내도 현재 위치에 맞춰 바뀐다. 기존 R은 Q와 같은 동작이다. 자동화·PIE·AI·독립 2인 검사와 패키징을 완료했고 새 게임 창을 실행했다.
- 최종 수동 실행 프로세스 응답, AI 생성과 2인 로비 초기화를 확인했다.
